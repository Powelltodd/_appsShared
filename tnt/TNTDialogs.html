QIRA is provided by EuroTramp (https://www.eurotramp.com/en/) to tie into the Trampoline to directly record and capture the horizontal displacement (HD) and Time-of-Flight (TOF) for the active gymnast. LiveMeet integrates with this win32 program to support pulling the HD and TOF for the OnDeck (active) score.

The following web page performs the necessary monitoring for LiveMeet to feed the current active score and athlete name to the running QIRA program.

Note: You will need to configure the Network settings in QIRA to have it push the HD and TOF to LiveMeet. The Client Settings should be Label=SportzSoft and URL=https://www.sportzsoft.com/ssRest/teamRest.dll. The Server Settings should be enabled on port 8080. The laptop you use for this requires an active internet connection.
